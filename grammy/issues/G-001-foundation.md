# G-001 — Fondasi Bun dan grammY

## Tujuan

Menyiapkan proyek TypeScript grammY dengan Bun sebagai satu-satunya tooling.

## Ruang lingkup

- package manifest;
- Bun lockfile;
- strict TypeScript;
- struktur source awal;
- konfigurasi test;
- aturan lint/format jika disepakati.

## Acceptance criteria

- seluruh perintah dokumentasi menggunakan Bun;
- tidak ada Node/npm/yarn/pnpm lockfile;
- proyek dapat di-install dan diverifikasi memakai Bun;
- belum ada koneksi ke token produksi.
